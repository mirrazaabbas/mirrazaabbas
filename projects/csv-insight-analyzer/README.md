# CSV Insight Analyzer

A beginner-friendly Python data analysis project that reads a sales CSV and produces useful business insights without external libraries.

## Why I built it
Business data often starts in spreadsheets and CSV files. This project demonstrates how Python can turn raw tabular data into concise decision-ready metrics.

## Features
- Reads CSV data using Python's standard library
- Calculates total, average, and median revenue
- Aggregates revenue by region and product
- Identifies the highest-performing region and product
- Includes a realistic sample dataset
- Requires no third-party packages

## Tech Stack
- Python
- CSV processing
- Statistics
- Data aggregation

## Run locally
```bash
python analyzer.py sample_sales.csv
```

## Example insights
The script reports:
- Number of rows analyzed
- Total revenue
- Average and median revenue
- Top-performing region
- Top-performing product
- Revenue breakdown by region

## Skills demonstrated
Data cleaning, numeric conversion, aggregation, descriptive statistics, business insight generation, and command-line application design.
